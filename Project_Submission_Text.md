## Project Name
LUNAR COMMAND: Mission Survival Simulator

## High-Level Project Summary
LUNAR COMMAND is an interactive, browser-based STEM game that puts learners in command of a simulated four-person lunar outpost for a 30-sol mission. Players balance oxygen, water, food, battery power, radiation shielding, thermal comfort and crew safety by choosing one engineering action each sol. Daily resource consumption and unexpected mission events demonstrate how improving one system can place pressure on another. The project turns the complex systems thinking behind a lunar habitat into an accessible, replayable learning experience.

## Detailed Project Description
LUNAR COMMAND is designed as a junior astronaut mission trainer. At the start of a mission, the learner receives a fixed set of simulated resources and must keep the crew safe until the end of a 30-sol mission. The interface displays live resource meters and a command log. Each sol, the player selects one action: recycle water and air, deploy a solar array, operate a greenhouse, add regolith shielding, enter conservation mode, or maintain critical systems. Actions have costs and benefits across multiple resources. The simulation then applies daily crew consumption and occasional events such as a solar activity alert, dust on solar arrays, greenhouse harvest or thermal stress. If essential resources or crew safety become critically low, the mission can end early. At the end, a debrief displays the score and remaining reserves.

The learning objective is to introduce systems thinking, resource management and engineering trade-offs. For example, greenhouse production can increase food and oxygen but consumes water and power; additional shielding improves protection but requires energy and crew effort. Learners can replay the mission and compare strategies.

The prototype is implemented as a self-contained HTML, CSS and JavaScript application. It requires no account, API key, database or installation: open `index.html` in a modern browser. The numerical values, resource costs, event probabilities and scoring are simplified educational game mechanics and are not flight-qualified engineering calculations.

## NASA Data
The project uses NASA public educational and technical resources as reference material for the lunar environment and habitat systems:
- NASA Moon Base Systems: https://www.nasa.gov/moonbase-systems/
- NASA Lunar South Pole Environment: https://www.nasa.gov/reference/moonbase-environment/
- From Apollo to Artemis: Exploring the Lunar Surface: https://www.nasa.gov/moonbase-environment-visualization/

These resources inform the simulated challenges involving habitation, life support, lunar dust, water ice, temperature extremes and radiation. The game does not ingest a numerical NASA dataset; its numerical game values are original illustrative assumptions.
